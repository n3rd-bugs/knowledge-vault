In Claude Code (CLI / IDE)

This gives that machine the kb_* tools and lets the session hooks capture your work automatically.

  1. Register the connector (uses the bearer above — reveal & paste it): 
    claude mcp add --transport http kb {{ mcp_url }} \
  --header "Authorization: Bearer <PASTE-TOKEN>"
    Note the host is {{ mcp_url }} — the MCP endpoint, not the REST host.
  2. Install the session hooks — simplest, just ask Claude Code: 
    run kb_setup and install the KB session hooks
    With the registration above present, the installer auto-detects MCP mode and needs no further token entry (flush-out on compaction + KB pre-brief on new sessions).
  3. Smoke-test the flush hook: 
    T=$(ls -t "$HOME"/.claude/projects/*/*.jsonl | head -1)
printf '{"transcript_path":"%s","cwd":"%s","session_id":"smoke"}' "$T" "$PWD" \
  | ~/.claude/hooks/flush-session-to-kb.sh
sleep 2 && tail -3 ~/.claude/hooks/flush-session.log   # expect: mcp … ok
